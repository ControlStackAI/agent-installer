## Arch Linux adapter

This image defaults to an Arch Linux target. Use the pinned Arch ISO, dated
package snapshot and signed, kernel-matched released ZFS packages. Read image
provenance at `/usr/share/agent-installer/arch-inputs.lock.json`.
Use Arch's official installation procedure, pacstrap, genfstab and arch-chroot
for approved manual work. Arch is rolling; explain that updates need kernel/ZFS
compatibility checks. Physical disk installation remains unqualified.
